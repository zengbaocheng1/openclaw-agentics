# openclaw-agentics 🐉
OpenClaw 智能体增强项目 — 自定义技能、工作流自动化、agent 增强模块

## 结构

```
skills/         - 自定义技能源码
scripts/        - 辅助脚本
workflows/      - 自动化工作流
config/         - 配置文件
docs/           - 文档
```

## 分支

- `main` - 稳定版
- `dev` - 开发版
- `feat/skill-xxx` - 技能功能分支

## 技能列表

| 技能名 | 功能 |
|--------|------|
| model-registry-manager | 模型注册表管理、去重、探测 |
| provider-probe | 模型供应商探活检测 |
| self-improving-agent | 自我反思与持续改进 |
| gstack-openclaw-investigate | 系统调试与根因分析 |
| gstack-openclaw-office-hours | 产品头脑风暴 |
| gstack-openclaw-ceo-review | CEO 级计划审查 |
| gstack-openclaw-retro | 工程回顾 |
| knowledge-learner | 知识学习与存储 |
| openclaw-backup | 备份与恢复 |
| openclaw-auto-updater | 自动更新调度 |

## 目标

持续积累 OpenClaw 技术实践，形成可复用的智能体增强框架。
